## Remote Mic Rune 2026.1111.0

This revision fixes a capture bug where a button press was silently ignored
right after the same button had been pressed.

### Highlights

- **Re-pressing the last button works again** — the agent reported each
  frame's press edges to the bridge but never committed the new pressed set,
  so the release of a button was never reported. The bridge kept the button
  marked as held, and the next press of that same button looked like "no
  change": its shortcut, media key or click did nothing. Pressing any
  different button in between worked, which made the bug look random.
  The pressed set is now committed with every edge, so release frames reach
  the bridge and every press fires.
- **Held-button lease expiry now releases cleanly** — the same stale state
  could also swallow the full-release line the agent sends when its lease
  expires while a button is held.

### Install

- **`remote-mic-rune-2026.1111.0-x86_64-pc-windows-msvc-setup.exe`** —
  per-machine install under `Program Files\Remote Mic Rune`; creates Start
  Menu and optional desktop shortcuts and an uninstaller. The installer stops
  a running helper task before upgrading and removes it on uninstall.
- **`remote-mic-rune-2026.1111.0-x86_64-pc-windows-msvc.zip`** — portable
  copy. Keep `rc_agent.dll` next to `rc-helper.exe`. For enhanced capture,
  use the installer (or another location the session-0 `WUDFHost` token can
  read); a per-user folder can make the agent DLL load fail.

After either install, open **Helper**, install the helper task (one UAC
prompt), then start it. Open **Capture** and enable enhanced capture.

### Verification

- 242 workspace tests pass, including a new regression test that walks a
  press, release and re-press of the same button through the report layer.
- Windows MSVC release build, produced by the release workflow.

## Remote Mic Rune 2026.1110.2

This revision simplifies button mappings to one action per button and keeps
the app running in the tray when its window is closed.

### Highlights

- **One action per button** — the separate double-press, long-press and
  hold-to-repeat bindings are gone. Every press fires the button's action:
  a double press fires it twice, and a long press fires it once.
- **Simpler Buttons page** — each card now has one action picker instead of
  three. Choosing **Shortcut** still opens the chord field under the card.
- **Existing settings upgrade** — `settings.json` keeps the old `single`
  action. Removed `double` / `long` / `hold_repeat` columns are ignored and
  disappear on the next save. A button that had only a double or long
  binding becomes unconfigured and needs a new action.
- **Close to tray** — closing the window hides it instead of exiting. The
  helper and bridge stay connected; use the tray's **Quit** item to exit.
- **Win+L safety** — a lock-workstation shortcut still waits for the
  physical release and then fires exactly once.

### Install

- **`remote-mic-rune-2026.1110.2-x86_64-pc-windows-msvc-setup.exe`** —
  per-machine install under `Program Files\Remote Mic Rune`; creates Start
  Menu and optional desktop shortcuts and an uninstaller. The installer stops
  a running helper task before upgrading and removes it on uninstall.
- **`remote-mic-rune-2026.1110.2-x86_64-pc-windows-msvc.zip`** — portable
  copy. Keep `rc_agent.dll` next to `rc-helper.exe`. For enhanced capture,
  use the installer (or another location the session-0 `WUDFHost` token can
  read); a per-user folder can make the agent DLL load fail.

After either install, open **Helper**, install the helper task (one UAC
prompt), then start it. Open **Capture** and enable enhanced capture.

### Verification

- 241 workspace tests pass.
- Windows MSVC release build, produced by the release workflow.
- Buttons page snapshots were checked in Chinese at normal and wide window

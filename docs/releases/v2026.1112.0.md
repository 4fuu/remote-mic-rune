## Remote Mic Rune 2026.1112.0

This revision adds the voice bridge: the remote's microphone audio now
reaches Windows.

### Highlights

- **Voice bridge** — a new section on the **Capture** page streams the
  remote's ATVV microphone audio into Windows. The RC003's microphone never
  appears as a recording device; the bridge decodes the proprietary
  16 kHz ADPCM stream over BLE GATT and writes the PCM into a virtual
  audio device's play endpoint (e.g. `CABLE Input` of VB-CABLE). A voice
  application reads the matching recording endpoint (e.g. `CABLE Output`).
- **How to use** — install a virtual audio device (VB-CABLE or Voicemeeter;
  the app does not bundle drivers), open **Capture → Voice bridge**, enable
  it, pick the device's play endpoint under **Output device**, and confirm
  the route with **Play test tone**. Then hold the remote's voice key and
  talk: the remote opens the mic itself, audio flows while held, and the
  release ends the stream.
- **Composes with voice-key synthesis** — synthesis (voice key → Alt) tells
  a listening application when you talk; the bridge delivers what you say.
  Enable both for the full push-to-talk experience with an IME or voice
  tool.
- **Gain and status** — a microphone gain picker (0–20 dB, +10 dB default),
  live connection status with battery, decoded-sample count and the last
  error, plus manual **Reconnect**.
- **Ported from a verified implementation** — the ATVV protocol layer,
  ADPCM decoder, WinRT GATT backend, audio pipeline and session handling
  are ported from `xiaomi-remote-mic`, which validated this exact code path
  on a real `2717:32B8` remote on 2026-08-25. The port keeps the protocol
  and session logic byte-for-byte where possible.
- Also includes the 2026.1111.0 fix: re-pressing the same button now fires
  its shortcut every time.

### Install

- **`remote-mic-rune-2026.1112.0-x86_64-pc-windows-msvc-setup.exe`** —
  per-machine install under `Program Files\Remote Mic Rune`; creates Start
  Menu and optional desktop shortcuts and an uninstaller. The installer stops
  a running helper task before upgrading and removes it on uninstall.
- **`remote-mic-rune-2026.1112.0-x86_64-pc-windows-msvc.zip`** — portable
  copy. Keep `rc_agent.dll` next to `rc-helper.exe`. For enhanced capture,
  use the installer (or another location the session-0 `WUDFHost` token can
  read); a per-user folder can make the agent DLL load fail.

After either install, open **Helper**, install the helper task (one UAC
prompt), then start it. Open **Capture** and enable enhanced capture.

### Verification

- 256 workspace tests pass, including the ported ATVV/ADPCM/session suites
  and new voice-settings round-trip and voice-section render tests.
- The voice bridge UI was snapshot-rendered in Chinese and English and
  inspected at 2x.
- The full workspace cross-checks clean for `x86_64-pc-windows-msvc`.
- The BLE/audio path itself needs real hardware: the release workflow built
  it, but the end-to-end voice stream is pending on-device validation. Voice

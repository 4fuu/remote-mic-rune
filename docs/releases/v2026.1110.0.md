## Remote Mic Rune 2026.1110.0

First release. Remote Mic Rune turns the Xiaomi RC003 (2 Pro) Bluetooth
remote into a fully programmable Windows remote, including the three keys
Windows drops before any user-mode input channel sees them: Back, Volume+,
and Volume−.

### Highlights

- **Report-layer capture** — `rc_agent.dll` is injected into the RC003's
  WUDFHost and intercepts `ntdll!NtDeviceIoControlFile` with Frida Gum's
  `Interceptor`; captured usages are cleared from keyboard report `0x01`
  before the kernel copies it.
- **13 semantic buttons** — Back, OK, TV, Home, Left/Right/Up/Down, Menu,
  Power, Volume mute/+/−.
- **Per-button gestures** — independent single press, double press, and long
  press bindings, plus hold-to-repeat.
- **Actions** — keyboard chords with modifiers, media keys, and mouse clicks.
- **Fail-open lease** — the agent stops touching reports within 2 seconds of
  losing the helper's lease; the remote returns to a plain keyboard.
- **Bilingual UI** — Simplified Chinese and English, following the system
  language by default with a manual switch in Settings.
- **Self-drawn Windows titlebar** — a 46 pt band with native caption buttons,
  snap layouts, window dragging, and double-click maximize/restore.

### Install

1. Download and extract
   `remote-mic-rune-2026.1110.0-x86_64-pc-windows-msvc.zip`.
2. Keep `rc_agent.dll` next to `rc-helper.exe`.
3. Run `rc-app.exe`.
4. Open **Helper**, install the helper task (one UAC prompt), then start it.
5. Open **Capture**, enable enhanced capture, and map buttons on the
   **Buttons** page.

Windows 10/11 x64 is required. The RC003 must be paired; RC001 report formats
are not supported by this version. The binaries are unsigned, so SmartScreen
may warn on first launch.

### Verification

- 251 workspace tests pass.
- The report-layer observe chain was validated on RC003 hardware, including
  live Back/Volume/OK/arrow edges and the lease.
- The Windows MSVC release build is produced by the release workflow with the
  Frida Gum hook and the embedded app icon.

### Known limitations

- The full canary and UI-chain acceptance pass is still a follow-up; the
  observe path and fail-open behavior are the verified parts.
- The GNU cross-build contains a fail-open agent stub without capture; use the
  MSVC build for the full feature set.
- The helper requires administrator installation once; see
  `docs/real-device-testing.md` in the repository for troubleshooting.
